## 핵심 도메인 계약

- `usedRatio`가 유일한 정본이며 내부 범위는 `0.0...1.0`이다.
- `remainingRatio`는 `1 - usedRatio` 계산 값이다.
- quota window마다 `source`, `contractKind`, `observedAt`, `freshness`, `resetsAt`을 보존한다.
- 한 Provider의 window와 credit은 각각 독립적으로 성공·실패할 수 있다.
- `nil`은 0% 또는 100%가 아니다.
- `stale cache`, `unsupported account`, `not configured`, `authentication required`를 구분한다.
- local token/cost는 quota 퍼센트를 계산하는 근거로 사용하지 않는다.
- 예상 소진은 동일 reset window의 충분한 fresh 표본이 있을 때만 계산한다.

권장 최소 protocol:

```swift
protocol QuotaProvider: Sendable {
    var id: ProviderID { get }
    func availability() async -> ProviderAvailability
    func fetchQuota() async -> ProviderFetchResult
}

protocol LocalUsageSource: Sendable {
    var provider: ProviderID { get }
    func loadUsage(in interval: DateInterval) async throws -> [LocalUsageSample]
}
```
