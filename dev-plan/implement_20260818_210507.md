# implement_20260818_210507.md

작성 일시: `2026-08-18 21:05:07 KST`

이 문서는 상태바 팝오버에서 한 번의 클릭으로 모든 Provider를 확인하는 전체 GUI를 여는 개발 범위를 고정하고, 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적

QuotaBeacon 상태바 팝오버 하단에 항상 보이는 **전체 보기** 버튼을 추가한다. 버튼을 누르면 팝오버를 닫고 기존 메인 대시보드의 개요 화면을 전면에 표시하며, 현재 지원하는 Claude·Codex·Grok·Gemini·GLM의 상태와 모든 quota window를 한 화면에서 빠르게 비교할 수 있게 한다. 기존 snapshot을 그대로 사용해 추가 Provider 호출이나 credential 접근을 만들지 않고, 기존 상태바·대시보드·연결·추세 동작에는 발견된 회귀 0건을 완료 조건으로 적용한다.

## 개발 범위

## 문서 기반 제약 사항

- menu와 dashboard는 같은 `ProviderSnapshot`을 소비하고 서로 다른 percent/reset 의미를 만들지 않는다.
- 누락된 window·ratio·reset은 0 또는 임의 시각으로 보완하지 않는다.
- quota urgency는 잔여량 기준을 유지하고 색상 외 텍스트·badge를 병행한다.
- Provider 표시 설정은 기존 계약대로 popover에만 적용하며 `전체 보기`는 지원 Provider 전체를 보여준다.
- popover footer는 scroll content 밖에 두고 선택 inspector 확장 시에도 압축·가림이 없어야 한다.
- 전체 보기 동작만으로 refresh를 시작하지 않는다. 이미 진행 중인 single-flight refresh와 snapshot을 그대로 사용한다.
- UI 이동을 위해 새로운 global singleton이나 별도 navigation framework를 추가하지 않는다.
- 기존 `menu.openDashboard` accessibility identifier는 호환성을 위해 유지하고 visible label/behavior 회귀 test를 보강한다.
