# implement_20260816_221218.md

작성 일시: `2026-08-16 22:12:18 KST`

이 문서는 QuotaBeacon 추세 화면을 실제 시계열 그래프로 재구성하는 범위를 고정하고, 시각 시안 확인 후 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적

현재 점 묶음으로 표시되는 quota history를 Provider·window·reset instance가 분리된 읽기 쉬운 선 그래프로 변경한다. 선택 기간과 실제 X축을 일치시키고, LIVE/캐시·위험 임계치·reset 경계를 시각화하여 사용자가 잔여량의 방향과 소진 위험을 빠르게 판단할 수 있게 한다.

## 개발 범위

- 실제 History를 선택 기간으로 필터링하는 trend presentation model
- Provider·quota window·reset instance 기준의 안정적인 series 식별
- `LineMark` 중심 그래프, 마지막 값 강조, 옅은 영역 표시
- 25% 주의·10% 위험 기준선과 QuotaBeacon 고유 `Reset Bands`
- LIVE/최근/캐시의 선 스타일·투명도 구분
- Provider 단일 상세와 전체 Provider small-multiples 모드
- 실제 수집 범위·표본 수·현재 잔여량·변화 속도·reset 요약
- series별 pace estimate와 데이터 부족 상태
- 추세 단위/UI test, 실제 XCUITest screenshot QA
- 관련 제품·아키텍처·QA 문서 갱신

## 제외 범위

- Provider 수집 계약·credential·network endpoint 변경
- History schema migration 또는 저장 기간 변경
- quota를 로컬 token/API 비용과 같은 축에 결합
- 데이터가 없는 로컬 token 그래프의 가짜 값 생성
- 부드러운 곡선 보간으로 실제 관측 사이의 값을 과장
- 외부 chart package 추가

## 현재 확인된 문제

- `range`가 panel 제목에만 쓰이고 날짜 필터·X축 domain에는 적용되지 않는다.
- quota graph가 `PointMark`만 사용해 방향성이 보이지 않는다.
- Provider 색과 window symbol 범례가 한곳에 섞여 시각적 해독 비용이 높다.
- 전체 Provider 5개 series가 기본 중첩되어 서로 다른 quota 의미가 뒤섞인다.
- `freshness`를 point에 저장하지만 선 스타일이나 opacity에 사용하지 않는다.
- reset instance가 바뀌어도 segment 경계를 표시하지 않는다.
- 현재 History는 400 snapshots, 266 points, 5 series이며 실제 수집 범위는 약 1시간 53분인데 화면 제목은 7일이다.
- 로컬 token panel은 실제 series가 연결되지 않은 고정 empty state다.
