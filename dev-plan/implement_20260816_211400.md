# implement_20260816_211400.md

작성 일시: `2026-08-16 21:14:00 KST`

이 문서는 사용자 제공 화면을 정보 구조 참고자료로만 사용하고, QuotaBeacon 고유의 `Beacon Ledger` GUI를 설계·구현·검증하기 위한 작업 문서다.

## 개발 목적

메뉴 막대에서 Provider별 quota 잔여량과 reset 긴급도를 한눈에 스캔하고, 선택한 Provider의 상세 window·출처·최신성을 같은 흐름에서 확인할 수 있는 native macOS GUI를 구현한다. 화면 밀도·표시 기준·reset 표기·테마·상세 inspector·Provider 노출을 설정에서 조정할 수 있게 하되, 제품의 출처·신뢰성 원칙과 스크롤 경계를 유지한다.

## 개발 범위

- `Beacon Ledger` 메뉴 막대 popover: scope 필터, 새로고침, Provider rail, mini quota meter, 선택 inspector
- 잔여량 중심의 `healthy / warning / critical` 시각 규칙과 색상 외 레이블 병행
- 균형/압축 밀도, 잔여/사용 표시, 상대/절대 reset, system/midnight/graphite 테마
- Provider별 popover 노출과 상세 inspector 표시 설정
- 대시보드 한도 화면을 동일한 ledger component와 정보 위계로 통합
- 설정 화면에 모양·표시 사용자화 GUI와 accessibility identifier 제공
- 단위/UI test, Release build, 설치본 교체, 실제 macOS GUI smoke QA
- 제품 범위·아키텍처·README·QA 문서 및 이 계획 상태 갱신
