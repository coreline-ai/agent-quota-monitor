## 잔여 리스크 / 후속 과제

- Claude snapshot bridge 설치는 `~/.claude/settings.json` 변경이므로 별도 승인이 필요하다.
- GLM은 실제 로그인에 사용한 command/path를 받아 official supported-tool 경로를 다시 확인해야 한다.
- Grok은 공식 machine-readable quota contract가 공개되기 전까지 수치를 표시하지 않는다.
- fresh XCTest 정본 갱신은 local Xcode test runner가 안정화된 환경에서 재실행한다.
