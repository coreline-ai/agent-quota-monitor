## 개발 목적

Grok Build `1.0.4`와 공식 xAI 공개 source에서 확인된 `grok agent stdio`의 `x.ai/billing` read-only JSON-RPC 계약을 QuotaBeacon에 연결한다. 기존 최상위 help 검사에서 발생한 false negative를 수정하고, 사용자가 명시적으로 승인한 경우에만 Grok CLI가 반환하는 주간 사용률·reset·선불 크레딧을 표시한다.

## 개발 범위

- 공식 Grok Build CLI의 `initialize` + `x.ai/billing` 전용 Provider adapter
- `creditUsagePercent`, `currentPeriod`, legacy billing field를 처리하는 신규 독립 parser
- Grok read-only 연결 opt-in 설정과 실행 파일 경로
- `grok agent stdio` capability 검사와 redacted 실계정 probe
- 정상·부분·오류·malformed fixture와 adapter contract test
- README, Provider 계약, 보안, QA, 검증 보고서의 status-only 판정 수정

## 제외 범위

- 외부 참조 source·fixture·구조의 복사 또는 제품 bundle 포함
- 브라우저 cookie, grok.com WebView, gRPC-web fallback 사용
- QuotaBeacon이 `~/.grok/auth.json` token을 직접 읽거나 HTTP header로 전송하는 방식
- login, logout, reauth, OAuth refresh, credential write-back

- `x.ai/auto-topup-rule` 또는 billing 외 JSON-RPC method 호출
