# implement_20260817_155407.md

작성 일시: `2026-08-17 15:54:07 KST`

이 문서는 Grok quota 시간 창을 공식 근거에 맞게 재검증하고, QuotaBeacon에 Gemini CLI Provider를 안전하게 추가하는 개발 범위를 고정하기 위한 작업 문서다.

## 개발 목적

- Grok에 5시간 quota가 있다는 추정과 현재 공식 계약을 분리한다.
- 공식 xAI 응답에 없는 Grok 5시간 수치를 만들거나 표시하지 않는다.
- 로그인된 공식 Gemini CLI가 제공하는 quota만 모델 호출 없이 읽어 QuotaBeacon의 다섯 번째 Provider로 표시한다.
- Gemini Code Assist 내부 서비스나 OAuth credential을 QuotaBeacon이 직접 호출·복제하지 않는다.
- 안정적인 기계 판독 계약이 확인되지 않으면 숫자를 추정하지 않고 명시적인 미지원 상태를 표시한다.

## 개발 범위

- xAI 공식 문서·설치된 Grok CLI·redacted billing 응답을 이용한 Grok window 계약 재검증
- Grok `periodType` schema drift 탐지와 주간/월간/알 수 없는 창의 보수적 정규화
- 공식 Gemini CLI 실행 파일·버전·인증 방식의 비밀정보 없는 탐지
- Gemini CLI의 `/stats model` 및 중첩 ACP/command surface 조사
- 공식 Gemini CLI 프로세스 경계 안에서 실행되는 read-only quota 수집 adapter
- Gemini 모델 quota의 `remainingFraction`, reset 시각, 모델/등급 레이블 정규화
- `ProviderID.gemini`, 설정, 메뉴바, 대시보드, 필터, 추세, 데이터 소스 화면 통합
- synthetic/redacted fixture, parser/provider/UI 회귀 테스트
- Provider 계약·제품 범위·보안·README 문서 업데이트

## 제외 범위

- 공식 응답으로 관측되지 않은 Grok 5시간 quota의 하드코딩 또는 추정
- Grok API의 RPS/TPM을 Grok 구독 quota로 합산
- Gemini 웹 앱, Gemini 모바일 앱, Antigravity quota 통합
- QuotaBeacon이 `oauth_creds.json`, `google_accounts.json`, API key 또는 refresh token을 읽는 구현
- QuotaBeacon이 Gemini Code Assist의 `retrieveUserQuota` 등 내부 endpoint를 직접 호출하는 구현
- 설치된 Gemini CLI bundle 내부 JavaScript를 runtime API나 링크 라이브러리로 사용하는 구현
- quota 확인을 위한 모델 prompt, 채팅, tool call, agent hook 실행
- Gemini API key·Vertex AI·조직 billing quota의 1차 구현
- Gemini 사용량이 없을 때 요금제의 정적 일일 한도만으로 사용률을 계산하는 구현
- 다른 Provider 추가, 대시보드 전면 재설계, 신규 외부 dependency 도입
