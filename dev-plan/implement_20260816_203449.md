## 확인 필요 사항 / 결정 기록

- 설치된 Orca는 OAuth usage를 우선하고 CLI `/usage`를 fallback으로 사용하며, statusLine `rate_limits`는 live-session 보강 경로로 사용한다.
- Orca의 직접 경로는 `Claude Code-credentials` Keychain JSON의 `claudeAiOauth.accessToken`을 읽고 `GET https://api.anthropic.com/api/oauth/usage`를 호출한다.
- request header는 bearer token, `anthropic-beta: oauth-2025-04-20`, Claude Code user-agent이며 cookie·request body는 없다.
- 승인된 1회 redacted probe에서 HTTP 200과 5시간·7일·Fable window를 확인했다. token·원본 payload는 출력·저장하지 않았다.
- 기존 구현이 놓친 핵심은 공식 statusline 문서만 제품 계약으로 고정하고, 실제 참조 구현의 Keychain OAuth primary path를 조사하지 않은 것이다.
- endpoint는 공개 stable API 문서가 아닌 first-party client 동작에서 관측한 계약이므로 `observed · Beta`로 표시한다.
