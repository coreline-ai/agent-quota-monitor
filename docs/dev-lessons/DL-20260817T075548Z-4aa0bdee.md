# TUI Provider probe는 spawn된 child slave PTY 크기를 명시한다

## 적용 범위와 비적용 조건

Expect 또는 유사 PTY transport로 interactive CLI의 read-only quota 화면을 수집하는 Provider adapter와 검증 probe에 적용한다. 비대화형 JSON command처럼 TTY rendering을 사용하지 않는 transport에는 비적용한다.

## 관측 사실과 영향

Antigravity CLI를 bounded Expect에서 실행했을 때 terminal control query만 반환되고 quota group marker가 나타나지 않았다. 동일한 CLI와 command는 일반 interactive terminal에서는 정상 출력되어 Gemini 연결 검증과 adapter 완성이 중단되었다.

## 근본 원인·기여 요인·근거

Expect 자체 terminal 설정만으로는 spawn된 child의 slave PTY 크기가 설정되지 않았다. child TUI가 0행 0열 terminal로 인식해 본문 layout을 렌더링하지 않은 것이 직접 원인이다. spawn child slave에 크기를 지정한 전후의 redacted group-marker 결과로 확인했다.

## 해결과 예방 control

interactive TUI를 자동화할 때 command 전송 전에 spawn child의 slave PTY에 유효한 rows와 columns를 명시한다. ready marker를 먼저 확인하고, fixed command allowlist, timeout, output cap, child cleanup, group-marker 검증을 함께 적용한다. control sequence만 받은 결과를 인증 또는 contract 미지원으로 오판하지 않는다.

## 검증

Gemini probe 테스트가 Expect script에 spawned child slave size 설정이 존재하는지 고정한다. 실제 read-only probe는 주간과 5시간 field, reset evidence, 다른 모델 그룹 제외, 설정 불변을 percentage나 account data 없이 확인했고 종료 후 child process가 남지 않았다.

## 발생 정보

OCC-GEMINI-002, 2026-08-17 KST. zero-size PTY 때문에 실제 TUI 계약이 없는 것처럼 보이는 material rework가 발생했다.

## 검토와 예외

Antigravity CLI의 TUI renderer, terminal protocol 또는 공식 machine-readable usage command가 변경될 때 재검토한다. 공식 비대화형 계약이 제공되면 PTY transport보다 이를 우선한다.
