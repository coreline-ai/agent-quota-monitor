## 개발 목적

상단 메뉴바 아이콘을 클릭했을 때 열리는 Beacon Ledger 팝오버의 Provider 목록 순서를 사용자가 직접 정하고, 앱을 재실행해도 그 순서를 유지할 수 있게 한다. 현재의 읽기 전용 quota 수집·정규화·refresh pipeline은 그대로 두고 화면 표시 순서만 사용자 설정으로 분리한다.

## 개발 범위

- 현재 지원하는 Claude·Codex·Gemini·Grok·Z.ai GLM 다섯 Provider의 전체 표시 순서 저장·복구
- 설정 화면 `표시와 밀도` 영역의 순서 편집 UI
- 드래그 이동과 키보드/버튼 기반 위·아래 이동 지원
- 상단 메뉴바 팝오버의 `모든 Provider`·`연결됨`·`주의 필요` 필터에 저장된 순서 적용
- 숨긴 Provider의 위치 보존과 새 Provider/손상된 저장값에 대한 결정적 보정
- 단위/UI 회귀 테스트와 README·아키텍처·제품 범위 문서 갱신

## 확인 필요 사항 / 결정 기록

- 여기서 말하는 `상단 상태바`는 현재 앱의 단일 `NSStatusItem` 아이콘과 그 안의 Provider Ledger 팝오버를 뜻한다. macOS 메뉴 막대에 Provider별 아이콘을 여러 개 추가하는 범위는 아니다.
- 현재 사용자에게 보이는 기본 순서는 문자열 정렬 결과인 `Claude Code → Codex → Gemini → Grok Build → Z.ai GLM`을 유지한다. 최초 실행·기존 사용자에게 새 설정값이 없을 때 이 순서를 사용한다.
- 순서 설정은 1차로 메뉴바 팝오버에만 적용한다. 대시보드 개요 카드, 한도, 추세, 데이터 소스의 기존 순서는 변경하지 않는다.
- 순서는 모든 Provider를 대상으로 저장한다. Provider를 숨겼다가 다시 켜면 사용자가 정한 기존 위치에 나타난다.
- 순서 변경은 화면 표현 설정이므로 연결 승인, credential 접근, process 실행, network refresh를 발생시키지 않는다.
